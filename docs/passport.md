# Паспорт проекта

## 1. Название проекта

Магазин обуви "Подкрадули".

## 2. Проблема

Малый бизнес в современном мире сильно страдает, если у магазина нет своего веб-сайта. Клиенты перед тем как прийти в офлайн магазин зачастую смотрят в интернете каталог товаров, а также люди сейчас привыкли заказывать онлайн.

## 3. Пользователи

Клиент магазина — выбирает товар и оформляет заказ; продавец-консультант — ведёт каталог и остатки; администратор — управляет пользователями и правами.

## 4. Цель проекта

Клиент будет видеть в любое время каталог магазина, у него будет возможность сделать заказ, забронировать нужную позицию. Продавец будет видеть актуальные остатки товаров, вести каталог.

## 5. Метрики успеха

- время оформления заказа — < 2 минут;
- клиент находит товар через поиск/фильтры — за < 3 кликов;
- остатки обновляются сразу после продажи, без ручного ввода;
- оформление заказа без авторизации;
- клиент может сохранять товары в отдельной папке "Мои пожелания";
- продавец может составлять актуальные сезонные каталоги.


## 6. Границы (что НЕ делаем)

Не подключаем реальные платёжные шлюзы (оплата — учебный симулятор); нет мобильного приложения; доставка - только самовывоз (забрать из офлайн магазина).

## 7. Риски

Не успеем метрики к дедлайну → приоритизация: сначала каталог и заказ, метрики в конце; сложно придумать 25+ товаров → берём реальный ассортимент из открытых источников.
